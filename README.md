A [make.fun](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) entry: the museum label a museum in the year 3000 puts beside an ordinary object from today — a traffic-light CAPTCHA, misread by the future with a straight face.

## The label

> Traffic Light Test, c. 2024. To prove they were human, people identified traffic lights in photographs. The machines passed every time. The people did not.

## Run it

```sh
python3 main.py
```

Writes one line (at most 200 characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Standard library only, deterministic.
